## Productivity Workspace: MATCHED NEGOTIATOR no longer has to match the typed NEGOTIATOR NAME

- A row generated from an uploaded record is now verified by that record. MATCHED NEGOTIATOR is the corrected name, so it can differ from the NEGOTIATOR NAME typed in the record without raising "No verified source record".
- Rows with no link to a specific uploaded record still need the matched employee to appear on the record for that property and date.
